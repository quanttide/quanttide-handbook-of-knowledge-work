# 工作物

工作物是知识工作的标准文档件：每件工作物在知识流动链中承担一个明确角色，维护方式由对应规格（目标/流程/验收）约束。

## 一般维护规则

从日志与档案两份规格推测的共性规则：

1. **角色唯一**：一件工作物在流动链中只承担一个角色——日志是捕获入口，档案是沉淀层，不混用。
2. **三段式流动**：接收上游 → 本地加工 → 转出下游；内容只向下游流动，不回流。
3. **单一去处**：每条内容每次流动只有一个明确去处。
4. **不留副本**：转出后上游不以原形式留存，每次流动上游净缩短。
5. **可再找到**：转出不是丢弃，内容在下游可被再次找到；暂无去处的留在原地等待。
6. **组织自主**：规格只约束流动方式，不约束工作物内部的组织形态。

## 规格

- [日志](journal.md)：捕获入口——捕获、整理、转出、清空。
- [档案](profile.md)：沉淀层——转入、组织、转出。
