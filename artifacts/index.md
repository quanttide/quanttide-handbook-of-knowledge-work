# 产物

## 目标

产物是知识工作的标准文档件：每件产物在知识流动链中承担一个明确角色，配一份规格约束其维护方式，使各产物可注册、可检验、可衔接成流动链。

## 流程

1. 注册：每件产物建一份规格，按「目标/流程/验收」三段编写，登记到本索引。
2. 维护：按各自规格维护，共性规则（从日志与档案推测）为——
   - 角色唯一：一件产物只承担流动链中的一个角色，不混用；
   - 三段式流动：接收上游 → 本地加工 → 转出下游，内容只向下游流动；
   - 单一去处：每条内容每次流动只有一个明确去处；
   - 不留副本：转出后上游不以原形式留存，每次流动上游净缩短；
   - 可再找到：暂无去处的留在原地等待，转出内容在下游可被再次找到；
   - 组织自主：规格只约束流动方式，不约束内部组织形态。
3. 检验：新增产物的规格即对共性规则的检验，出现反例时修正规则而非硬套。

## 验收

- 每一个产物有自己的时态和生命周期（语境除外——它无时态，只保留当前生效版本）。
- 每件产物在本索引有登记，规格为目标/流程/验收三段。
- 每条内容流动有单一去处，上游不留副本。
- 共性规则被全部产物规格遵守，反例出现时规则已同步修正。

## 规格

- [语境](context.md)：驱动型·无时态——驱动层——沉淀、修订、加载。
- [日志](journal.md)：陈述型·现在×事件类——状态线索——捕获、整理、分流、清空。
- [档案](profile.md)：陈述型·现在×语义类——沉淀层——转入、组织、转出。
- [意图](intention.md)：陈述型·未来×自我类——方向层——转入、组织、归档。
- [洞察](insight.md)：陈述型·未来×语义类——认知层——转入、组织、修订。
- [手册](handbook.md)：程序型·法律·人类友好——集合载体——注册、维护、发布。
- [路线图](roadmap.md)：陈述型·未来×事件类——排序层——转入、组织、勾销。
